## 📖 About The Project

<img src="Nike%20Product%20Card/assets/images/desktop.png" alt="Nike Product Card Desktop Screenshot" width="100%"/>

**Nike Product Card** is a visually appealing and minimal product display section ideal for highlighting **Nike shoes** or other branded products.  
The layout uses **modern UI principles**, subtle hover effects, and responsive design — giving users a premium feel while browsing products.  
It can easily be integrated into larger eCommerce websites or used as a standalone component in product galleries.


---

### ✨ Features

- Responsive product card layout  
- Smooth hover and transition animations  
- Modern typography and branding  
- Clean, minimal, and professional design  
- Lightweight and easy to customize
